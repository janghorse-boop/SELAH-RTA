# 확인하지 못한 것

날짜: 2026-09-29 · 근거: `docs/review/` 의 독립 검토 요청서 열한 편

> **왜 이 문서가 있는가**
>
> 「이 앱에서 우리가 **모르는 것**이 무엇인가」에 답하려면 지금까지는
> 요청서 열한 편을 뒤져야 했다. 그 목록은 회차마다 끝에 한 번씩 적히고
> 다음 회차로 넘어가면 묻힌다.
>
> **모르는 것을 모아 두지 않으면, 모른다는 사실이 사라진다.** 그러면
> 「시험이 다 통과했으니 됐다」가 된다 — 이 저장소가 열한 회차 동안
> 거듭 데인 자리가 바로 그것이다.
>
> 묶는 기준은 **왜 확인 못 하는가**다. 그래야 **누가 닫을 수 있는지**가
> 보인다.

---

## 1. 사람과 장비가 있어야 닫힌다 (담당자 몫)

| 무엇 | 왜 못 했나 | 무엇이 있으면 닫히나 |
|---|---|---|
| **실제 PA 에서 귀로** 「딱」 소리가 사라졌는지 | 파형이 이어진 것과 **들리는 것**은 다른 말이다 | 예배당·PA·귀 |
| 손가락으로 슬라이더를 끄는 동안 **눈에 부드러운지** | 잰 것은 주 스레드가 잡히는 시간이지 **그려진 프레임 수**가 아니다 | 실기기에서 직접 끌어 보기 |
| 교정기 **94/114 dB 음향 정확도** | 교정기가 없다 | 음압 교정기 |
| **기준 소음계와의 절대 비교** | 기준기가 없다 | 기준 소음계 |
| **실제 업로드 키**로 서명하는 전 과정 | **키스토어는 비밀값이라 만들지 않는다** | 사람이 [release-signing.md](release-signing.md) 대로 생성 |
| Play Console **등록·대조**, 데이터 안전 항목 | 계정 작업이다 | 사람 |
| **USB 오디오 인터페이스** 실기기 전환·CAL 적용 | 인터페이스·측정 마이크가 없다 | USB Audio Class 기기 + 측정 마이크 |
| 제조사 **기기 이전 도구**(Smart Switch) | 폰 두 대가 필요하다 | 폰 두 대 |

## 2. 시험으로 **일으킬 수 없다** (구조상)

여기 있는 것들은 「시험을 더 쓰면 된다」가 아니다. **일으킬 방법이 없다.**

| 무엇 | 왜 못 일으키나 |
|---|---|
| **이어폰·USB 를 실제로 뽑는 것** | `ACTION_AUDIO_BECOMING_NOISY` 는 **시스템만 보낼 수 있는 보호된 방송**이다. 셸에서도 시험에서도 못 보낸다. 수신기가 붙고 떨어지는 것까지만 확인했다 |
| 전화 수신·다른 앱 선점으로 **진짜 포커스를 잃는 것** | 시험은 리스너에 값을 **직접 넣는다**. 실제 경로를 지나지 않는다 |
| **프로세스가 죽는 순간**의 원자적 쓰기 | 시험이 제 프로세스를 죽일 수 없다. 대신 **끝 표시(`end=1`)** 로 잘린 겉장을 막고, 그쪽은 시험으로 덮었다 |
| 화면 종료 중 **느린 장치 열기** | 계측에서 `open` 을 빗장으로 붙들어 순서는 고정했지만, **실제로 느린 장치**는 못 만들었다 |

### 2-1. 두 그물이 서로를 가려 **구별되지 않는** 자리

이것들은 **일부러 이중으로 막아** 둔 곳이다. 앞쪽이 성한 동안 뒤쪽이
빠져도 **어떤 시험도 알아채지 못한다**(변이로 확인했다).

- `RtaCaptureRun` 의 `average.reset()` — 앞쪽(안정화 중 안 쌓기)이 성하면
  구별 불가. 앞쪽은 「안정화 중에는 한 장도 안 쌓인다」가 직접 본다.
- `RtaMeasurementStore` 의 **원자적 바꿔치기** — 끝 표시가 성하면 구별
  불가(위 표 참고).

**지우지 않는다.** 구별이 안 된다는 것이 필요 없다는 뜻은 아니다.

## 3. 시간이 있어야 닫힌다

| 무엇 | 얼마나 |
|---|---|
| **장시간 부하**(예배 두 시간) — GC pause, p95/p99, 열 | 2시간 |
| 예배당에서 **10초 평균이 충분히 가라앉는지** | 현장 1회. 저역은 더 걸릴 수 있다 |
| 저장 기록이 **쌓였을 때** 목록이 쓸 만한지 | 실제 사용 몇 주 |
| 하울링 탐지의 **현장 오탐률·놓침률·검출 지연** | 실제 예배 |

## 4. 환경이 달라야 닫힌다

- **44.1kHz 출력 경로 전반.** 지금 내보내는 쪽은 48kHz 로 고정이다.
  44.1kHz 를 쓰게 되면 맨 위 20kHz 대역은 위 경계가 나이퀴스트를 넘어
  **폭이 좁아진다**(중심은 맞는다). 그때 화면에서 막거나 잘린 대역임을
  적어야 한다.
- **조용한 환경 측정.** 사무실에서 잰 값이라 주변 소음이 섞여 있다.

## 5. 눈으로만 본 것 (시험 밖)

시험이 지나지 않는 **한 줄**들이다. 기기에서 눈으로 확인했고, 그 사실을
그대로 적는다.

- `SelahApp` 이 `AppBottomArea` 를 부르는 한 줄 — 그 아래는 계측 시험이
  덮는다.
- 「RTA에서 재기」를 누른 **뒤에 소리가 실제로 이어지는지** — 콜백까지만
  시험이 보고, 그다음은 기기에서 봤다(`AudioTrack state:started` 확인).
- 겹친 곡선이 **눈에 갈리는지**(색·굵기), 미니 바가 분석 화면의 자리를
  얼마나 가져가는지.

## 이미 닫힌 것

옛 요청서에 미검증으로 적혔다가 그 뒤 해결된 것들이다. **지우지 않고
남긴다** — 「그때는 몰랐다」가 기록으로 남아야 한다.

| 무엇 | 언제 |
|---|---|
| 지시서 §5 오디오 포커스·이어폰 뽑힘(`Interrupted`) | 2026-09-29 (14) |
| 지시서 §7 저장·겹쳐 보기 | 2026-09-29 (15) · 자동 차이 (17) · 차례 (19) |
| `doFirst` 서명 검사가 코드에 없던 것 | 2026-09-29 UISRFFF |
| 임시 키로 `bundleRelease` 전 과정 | 검토자가 6회차에 대신 확인 |

---

## 이 문서를 고치는 때

- 새 기능을 내면서 **확인 못 한 것이 생기면** 여기에 적는다. 요청서에만
  적으면 다음 회차에서 묻힌다.
- 장비가 생기거나 현장에서 확인하면 **「이미 닫힌 것」으로 옮긴다.**
  지우지 않는다.

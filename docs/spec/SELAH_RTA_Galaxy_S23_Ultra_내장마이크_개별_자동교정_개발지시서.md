# SELAH RTA 개발지시서: Galaxy S23 Ultra 내장 마이크별 자동 주파수 응답 교정

## 1. 목적과 범위

기존 **UMC404HD + EMM-6 USB 입력 기능**을 기준 측정 경로로 활용하여 Galaxy S23 Ultra의 후면 마이크와 하단 마이크를 **각각 독립적으로 식별하고 녹음할 수 있는 경우에 한해** 별도의 주파수 응답 보정 프로파일을 생성·저장·적용한다. 물리 마이크 분리가 Android 공개 API 및 실기기에서 확인되지 않으면 두 개의 프로파일을 임의로 만들지 않는다. 기존 USB 입력 지시서의 장치 인식, 입력 채널, +48V 안내, EMM-6 개별 CAL 적용, 신호 레벨·클리핑 확인, 연결 해제 처리를 재사용한다.

이 문서는 기능 요구사항이다. 현재 SELAH RTA 코드 구조와 실제 Galaxy S23 Ultra의 Android/One UI 버전을 먼저 확인하고 구현 지점을 정한다. 기기 모델명만으로 `후면`·`하단` 마이크 ID 또는 채널을 하드코딩하지 않는다.

## 2. 물리 마이크 탐색과 선택 가능성 판정

1. `RECORD_AUDIO` 권한을 확인하고 `AudioManager.getDevices(GET_DEVICES_INPUTS)`, `AudioManager.getMicrophones()`로 현재 입력 장치와 마이크 메타데이터를 수집한다. `MicrophoneInfo`의 ID, 위치·방향, 그룹/인덱스, 연결 장치 ID와 사용 가능한 채널 정보를 진단 화면·로그에 기록한다. 위치 정보는 후보 식별에만 사용한다.
2. 내장 마이크 후보별로 실제 `AudioRecord`를 시작한다. 가능한 경우 입력 `AudioDeviceInfo`에 `setPreferredDevice()`를 적용하고, 방향 선택 API는 힌트로만 사용한다. 각 녹음 중 `getRoutedDevice()`와 `getActiveMicrophones()` 및 각 마이크의 채널 매핑을 확인한다. 필요하면 입력 소스·채널 구성별로 탐색한다. 선호 장치 지정 성공, 방향 지정 성공, 목록에 마이크가 보인다는 사실만으로 물리 마이크 선택 성공으로 간주하지 않는다.
3. 후면·하단 후보 각각에 가까운 위치에서 통제된 짧은 신호/가림 테스트를 실시하여 활성 마이크·채널 정보와 측정 레벨 변화를 함께 확인한다. 사용자에게 물리 위치를 확인받고, 식별 근거와 확신 수준을 기록한다. 한 녹음 스트림에서 두 마이크가 섞이거나 빔포밍·자동 전환되면 단일 물리 마이크 프로파일로 표시하지 않는다.
4. 녹음 중 경로 변경, USB 연결·해제, 앱 재시작 후에도 실제 활성 마이크가 일치하는지 재확인한다. 마이크 ID 또는 채널 매핑의 재현성이 부족하면 해당 프로파일 자동 적용을 차단한다.
5. 실기기에서 **독립 선택·식별 가능**, **논리 입력만 구분 가능**, **구분 불가**의 세 상태를 명시한다. 첫 상태에서만 `후면`·`하단` 개별 자동 교정을 제공한다. 두 번째 상태에서는 확인된 입력 경로 프로파일로만 저장하고 물리 위치 이름을 붙이지 않는다. 세 번째 상태에서는 개별 교정을 비활성화하고 이유를 설명한다.

## 3. 교정 전 점검

- EMM-6를 UMC404HD의 선택한 입력에 연결한다. UMC404HD의 **하드웨어 +48V 스위치를 사용자가 켜도록 안내**한다. 앱은 팬텀전원 상태를 제어하거나 확정 표시하지 않고, 실제 신호·노이즈·클리핑만 확인한다.
- EMM-6 개별 CAL 파일을 로드하고 파일 형식, 주파수 범위, 보정 부호, 보간 결과를 검증한다. 기준 측정에는 해당 CAL을 적용한다. 적용 여부와 파일 식별자를 세션에 남긴다.
- Android 입력 소스 `UNPROCESSED` 지원 속성을 확인하고 지원 시 우선 시도한다. 미지원이면 `VOICE_RECOGNITION` 등 후보를 실측 비교한다. `AutomaticGainControl`·`NoiseSuppressor`·`AcousticEchoCanceler`의 가용성 및 현재 세션의 활성화 상태를 확인하고 가능한 경우 비활성화한다. API 설정값만 신뢰하지 말고 일정 레벨 신호의 시간별 이득 변화, 스펙트럼 변형, 반복 측정으로 잔여 DSP를 검사한다. 우회가 검증되지 않으면 교정을 중단하거나 `제한적 정확도`로 명시하고 자동 적용을 금지한다.
- USB 기준 경로와 내장 마이크 경로의 실제 sample rate, 채널, 입력 소스, 신호 레벨을 기록한다. 클리핑, 너무 낮은 SNR, 앱/통화에 의한 녹음 경로 변경, 외부 마이크 자동 선택을 감지하면 측정을 중지한다.

## 4. 권장 교정 절차

1. 조용하고 반사가 적은 환경에서 고정된 스피커로 **핑크 노이즈 또는 로그 스윕**을 재생한다. 스피커·볼륨·휴대전화 자세·측정 방향을 고정하고 충분한 SNR을 확보한다. 내장 스피커를 테스트 신호원으로 쓸 경우 자체 DSP와 마이크 간 음향 결합의 영향을 별도로 평가한다. 가능한 경우 외부 스피커를 권장한다.
2. EMM-6 캡슐과 교정 대상 내장 마이크 입구가 가능한 한 같은 공간점을 향하도록 지그 또는 위치 표시를 사용한다. 두 마이크를 정확히 같은 공간점에 동시에 놓을 수 없으므로 **순차 측정**을 기본으로 하고, 기준 측정 → 대상 측정 → 기준 재측정 순서로 스피커·환경의 변화를 확인한다. 기준 재측정 편차가 허용 범위를 넘으면 재시도한다. 두 장치의 동시 캡처가 가능하더라도 위치 차이는 제거되지 않는다.
3. 후면과 하단을 각각 선택·검증하고 독립 세션으로 측정한다. 마이크 입구를 가리지 않도록 고정하고, 주변 사람·반사면·폰 방향을 바꾸지 않는다. 각 마이크에 적합한 실제 측정 위치와 허용 오차는 실기기 반복 측정으로 정한다.
4. 각 세션에서 여러 회 측정하여 불안정 구간을 배제한다. 로그 스윕은 시간 정렬·디컨볼루션 후 유효 응답을 추출하고, 핑크 노이즈는 충분한 평균과 동일 분석 창/FFT 설정을 사용한다. 스피커 출력 변동 및 전체 입력 이득 차이는 신뢰할 수 있는 중역 기준 대역에서 **레벨 정규화**한다.
5. EMM-6 CAL 적용 응답과 내장 마이크 응답을 공통 **로그 주파수 축**에 보간한다. `correction_dB(f) = reference_dB(f) - internal_dB(f)`로 보정 곡선을 계산한다. 적절한 fractional-octave smoothing을 적용하고, 측정 범위 밖·저 SNR·불안정한 좁은 피크와 딥에서는 보정값을 제한하거나 무효 처리한다. 정규화 기준 대역, smoothing 폭, 보정 상한과 유효 주파수 범위는 설정값과 결과에 저장한다.
6. 보정 전/후 응답, 반복 측정 편차, 적용 가능한 주파수 범위, 처리된 입력 경로를 미리 보여준다. 사용자가 승인하면 해당 마이크/경로 프로파일을 저장한다. 보정 곡선은 RTA 스펙트럼 표시·분석에서 지정된 단계에 **한 번만** 적용하고 원시 측정값은 유지한다.

## 5. 절대 SPL과의 분리

이 기능은 **상대 주파수 응답**을 보정한다. 레벨 정규화로 절대 dB SPL 정확도를 얻었다고 표시하지 않는다. 절대 SPL 교정은 별도 음압 캘리브레이터와 입력 이득·경로 검증을 요구하는 독립 절차/값으로 관리한다. UI와 데이터 모델에서 `주파수 응답 보정`과 `절대 SPL 보정`의 상태를 분리한다.

## 6. 프로파일 데이터 및 적용 규칙

프로파일마다 최소한 다음을 저장한다.

| 항목 | 내용 |
|---|---|
| 식별 | 프로파일 UUID, 표시 이름, 생성·수정 시각, 스키마/알고리즘 버전 |
| 기기 | 제조사·모델, Android/One UI 버전 또는 빌드 식별자 |
| 마이크 | 실제 확인된 `MicrophoneInfo` ID·위치·그룹·인덱스, `AudioDeviceInfo` ID/유형, 활성 마이크·채널 매핑, 사용자 확인 위치, 식별 확신 수준 |
| 오디오 경로 | 녹음 소스, 실제 라우팅 장치, sample rate, 채널 구성, DSP 검사 결과, 입력 경로 식별자 |
| 기준 경로 | UMC404HD 장치·입력 채널, EMM-6 CAL 파일 식별자/해시, CAL 적용 상태 |
| 교정 | 주파수 배열·보정 dB 배열, 유효 범위, 정규화 대역, smoothing·보정 제한값, 품질 지표·검증 결과 |
| 상태 | 활성 여부, 마지막 검증 시각, 재교정 필요 사유 |

앱 재시작 시 현재 **실제 활성 마이크·채널·입력 경로·sample rate**와 프로파일 조건을 다시 대조한다. 일치하지 않으면 자동 적용하지 않고 이유를 알린다. OS 업데이트, 경로/채널 변화, 케이스나 기구 변경, 반복 검증 실패 시 재검증 또는 재교정을 제안한다. 후면·하단 프로파일은 서로 덮어쓰지 않으며 수동 ON/OFF 및 삭제가 가능해야 한다. 프로파일 데이터는 버전 관리하고 손상·구버전 파일에 대한 안전한 마이그레이션/비활성화 경로를 둔다.

## 7. UI 요구사항

- `내장 마이크 탐색`: 발견된 입력 경로, 활성 물리 마이크와 채널, 후면/하단 판정 근거, 선택 가능 상태를 표시한다. 물리 마이크 판정이 불가하면 두 마이크 선택 버튼을 제공하지 않는다.
- `교정 마법사`: 기준 장비 연결·CAL·+48V 안내 → DSP 및 신호 점검 → 대상 마이크 확인 → 기준/대상/기준 측정 → 곡선 검토 → 저장의 순서로 진행한다. 오류 시 해당 단계에서 복구 방법을 제시한다.
- `프로파일 관리`: 마이크별 프로파일 목록, 보정 전/후 그래프, 품질·유효 범위, ON/OFF, 재검증·재교정, 삭제를 제공한다. 적용 중인 마이크/경로와 프로파일 이름을 RTA 화면에 표시한다.
- 절대 SPL이 미교정이면 별도 상태로 명확히 표시한다.

## 8. 테스트와 완료 조건 (Definition of Done)

1. Galaxy S23 Ultra **실기기**에서 Android/One UI 빌드별 마이크 목록, 위치 메타데이터, 실제 활성 마이크·채널 매핑, 경로 전환 결과를 기록한다. 두 물리 마이크가 공개 API로 분리 가능한지 결과를 보고한다. 불가능하면 제품에서 이를 정직하게 표시하고 개별 프로파일을 생성하지 않는다.
2. 후면과 하단이 분리 가능한 빌드에서는 각 마이크를 선택했을 때 실제 활성 마이크가 일치하고, 서로 다른 프로파일 생성·저장·재시작 후 재적용·ON/OFF·삭제가 검증된다. 오디오 경로 변경 시 잘못된 프로파일 적용이 차단된다.
3. EMM-6 CAL 적용, 보정 부호, 로그 주파수 보간, 정규화, smoothing, 유효 범위, 한 번만 적용되는 처리 순서를 알려진 합성 응답 데이터로 검증한다.
4. 실기기에서 반복 측정과 독립 재측정으로 보정 전/후 주파수 응답 편차를 비교한다. 허용 오차·주파수 범위·SNR 기준은 사전 정의하고 측정 결과와 함께 보고한다. 단일 측정의 좋은 그래프만으로 완료 처리하지 않는다.
5. AGC/NS/AEC 비활성화·우회 가능 여부를 설정값과 신호 테스트로 확인한다. 우회 불가 또는 자동 라우팅/혼합이 있으면 품질 제한과 적용 차단 동작을 검증한다.
6. USB 분리, 팬텀전원 미설정으로 인한 무신호, 클리핑, CAL 누락/오류, 마이크 권한 거부, 스피커 출력 변화, 앱 재시작, OS 업데이트 후 메타데이터 변화에서 안내·복구·안전한 비활성화가 동작한다.
7. 완료 보고서에 구현 파일, 실기기/OS 버전, 실제 지원되는 물리 마이크 선택 범위, 테스트 데이터와 전/후 그래프, 알려진 한계, 재교정 조건을 포함한다.

# 하울링 탐지에서 지금 정한 것과 아직 모르는 것

날짜: 2026-09-21 · 상태: 받아들임
계기: Codex 독립 검증 [Phase 9](../review/SELAH-RTA-phase9-independent-review.md)

명세 24.1 은 「Medium 은 영향과 일정에 따라 처리 결정을 ADR 에 남긴다」고
한다. 고친 것은 코드에 있고, **고치지 않기로 한 것과 아직 모르는 것**을
여기 적는다.

## 1. 합성 입력을 걷어냈다 (P9-06)

명세 16장은 「Debug build 에서 synthetic AudioSource 주입」을 요구한다.
구현은 했지만 **화면에서 고를 방법을 붙이지 않아 죽은 코드**였다. 검증자는
진입점을 붙이라고 권했고, **사용자는 걷어내기로 정했다.**

**왜 걷어내는가**

- **시험 신호 발생기가 그 자리를 대신한다.** 스피커로 내보내고 마이크로
  받으면 **실제 음향 경로 전체**를 지난다. 합성 입력은 마이크를 건너뛰므로
  더 적게 검증한다.
- 명세 0장은 「입력이 없을 때 Mock 숫자를 실제 측정값처럼 표시하지
  않는다」고 못박았다. 마이크가 아닌 숫자를 화면에 띄우는 경로를 하나 더
  두는 것은 그 취지와 어긋난다. 이름표로 가릴 수는 있지만 **없는 편이
  안전하다.**
- 실제로 1kHz·4kHz 를 스피커로 내보내 탐지를 확인했다. 합성 입력 없이도
  검증이 됐다.

**무엇을 잃는가** — 마이크 없이 **정확히 아는 PCM** 으로 DSP·UI 연결을
재현하는 길이 없다. 검증자가 그 가치를 지적했고 맞는 말이다. 스피커를 쓸
수 없는 환경(조용해야 하는 자리, 자동 시험)에서는 아쉽다.

**되돌릴 조건** — Phase 12(정확도 검증)에서 아는 신호를 마이크 없이 넣어야
할 일이 생기면 그때 다시 만든다. 그때는 debug 빌드 격리와 진입점을 함께
만든다.

## 2. 문턱값은 전부 잠정이다 (검증자 판단 1번)

| 무엇 | 값 | 근거 |
|---|---:|---|
| 솟음 | 10dB | 없음 — 핑크 잡음의 우연한 봉우리가 11~12dB 이라 그 위 |
| 폭 | 5칸 | 4096점 Hann 순음이 2~3칸이라 넉넉히 |
| 레벨 | −70dBFS | 고요 속 봉우리를 거르는 선 |
| 의심 | 300ms | 없음 |
| 지속 | 1500ms | 없음 |
| 흔들림 | 35cent | 비브라토가 보통 ±50~100cent 라는 것에서 |
| 연속성 | 0.85 | 없음 |
| 배음 기다림 | 3배 | 없음 |

**규격에서 온 값이 하나도 없다.** 개발용 신호를 통과했다는 것이 현장
오탐률을 말해 주지 않는다. 검증자가 짚은 대로다.

**또 하나** — 폭(5칸)과 둘레(48칸)는 **Hz 폭이 아니라 칸 수**다.
샘플레이트나 FFT 길이가 바뀌면 실제 주파수 폭이 달라진다. 지금은
48kHz·4096 만 쓰므로 문제가 드러나지 않지만, 44.1kHz 기기에서는 10% 좁아진다.

**언제 정할 것인가** — Phase 16(현장 Pilot)에서 실제 설교·찬양으로 조정한다.
그 전까지 이 값들은 **잠정**이고, 화면은 「후보」라고만 적는다.

## 3. 탐지는 보정 전 스펙트럼을 본다 (검증자 판단 3번)

마이크 보정 곡선을 걸기 **전** 스펙트럼에서 봉우리를 찾는다.

**왜** — 보는 것이 「둘레보다 얼마나 솟았는가」라서, 봉우리와 둘레에 비슷한
보정이 걸리면 차이가 거의 안 바뀐다.

**그 근거의 한계** — 검증자가 옳게 짚었다. 응답이 **가파르거나 notch 가
있는 구간**에서는 봉우리와 둘레에 서로 다른 이득이 걸려 솟음이 달라진다.
「거의 안 바뀐다」는 **일반적인 보장이 아니다.**

**지금 정하는 것** — 후보 탐지는 **센서가 받은 신호 기준**이라고 정의한다.
`levelDbfs` 는 보정하지 않은 칸 전력이며 **밴드 RMS 나 SPL 과 같지 않다.**
화면에서 이 값을 음압처럼 쓰지 않는다.

**언제 다시 볼 것인가** — 가파른 곡선·notch 곡선으로 보정 전후 검출률을
견주는 시험을 Phase 12 에 넣는다.

## 4. 아직 모르는 것

**가장 중요한 것이 미확인이다.**

- **현장 오탐률** — 실제 찬양에서 얼마나 뜨는지 모른다. 오르간·플루트·
  신시사이저·합창처럼 길게 끄는 소리가 많은 예배에서 특히 그렇다.
- **놓침률·검출 지연** — 실제 PA 폐루프에서 생기는 하울링을 얼마나 빨리
  잡는지 모른다. 스피커로 순음을 낸 시험은 **안정된 협대역 음의 탐지**를
  확인한 것이지 폐루프 피드백의 재현이 아니다.
- **2.5초 악기 시험은 4.5초 뒤를 말해 주지 않는다.** 배음이 있으면 3배를
  기다리게 해 뒀는데, 그 뒤에도 계속 끄는 오르간은 「지속」이 된다.

이 셋은 **Phase 16 현장 Pilot** 에서 답한다. 그때까지 화면은 「후보」라고
적고, 「의심」 단계에서는 EQ 를 만지라고 하지 않고 **먼저 들어 보라고**
안내한다.

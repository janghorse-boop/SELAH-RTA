# 측정 정확도의 한계를 어디까지 인정하고, 어디에 적을 것인가

날짜: 2026-09-21 · 상태: 받아들임
계기: Codex 독립 검증 [R04·R08](../review/2026-09-21-phase4-8-codex-review.md)

## 문제

지금 구현에는 **고치지 않고 남겨 둔 오차**가 둘 있다. 둘 다 「작으니까
괜찮다」고 적어 두었는데, 독립 검증이 그 근거가 성립하지 않는다고 지적했다.

근거가 틀린 채로 「작다」고 적어 두는 것이 실제 오차보다 나쁘다. 담당자는
그 문장을 읽고 숫자를 믿기 때문이다.

## 결정

두 한계를 **그대로 두되**, 크기를 재서 적고 화면에도 알린다.

### 1. 주파수 보정은 RTA 에만 걸린다 (R04)

마이크 보정 곡선은 31밴드 막대에만 적용한다. 큰 음압 숫자(dBA·Leq·MAX·PEAK)
에는 들어가지 않는다.

**왜 안 거는가** — 주파수별 보정을 광대역 음압에 제대로 걸려면 시간 영역에서
역응답 필터를 통과시켜야 한다. 「밴드마다 고쳐서 다시 합치는」 손쉬운 방법은
쓸 수 없다:

- 규격의 Fast/Slow 는 **시간 영역 신호**의 지수 가중이지 밴드 합이 아니다.
- 파형 PEAK 은 밴드로 되살릴 수 없다. 클리핑 판정도 마찬가지다.

**남는 오차의 크기** — 예전에 여기 적었던 「±2dB 마이크면 광대역 영향이
0.5dB 아래이고 전대역 보정이 흡수한다」는 **일반적으로 틀리다.** 남는 오차는
보정을 맞춘 주파수의 응답과 실제 소리가 놓인 주파수의 응답 **차이**다.

| 상황 | 남는 오차 |
|---|---|
| 1kHz 에서 보정, 마이크의 125Hz 응답 +2dB, 저역 위주 소리 | +2dB |
| 보정 기준 대역 −2dB, 측정 대역 +2dB | 4dB |
| 응답이 평탄한 마이크(측정용) | 거의 0 |

C−A 도 마찬가지다. 전대역 보정값은 양쪽에서 상쇄되지만 **마이크 응답의
기울기는 상쇄되지 않는다.**

**어디에 적는가**: `CurveStore.FREQUENCY_SCOPE_NOTE` — 보정 카드에 그대로 뜬다.

### 2. 저역 밴드는 FFT 창이 다 담지 못한다 (R08)

4096점·48kHz 에서 낮은 밴드는 순음 에너지의 일부가 이웃으로 새어, 실제보다
낮게 나온다. 재어 본 값(밴드 안 세 자리 중 가장 나쁜 것):

| 밴드 | 새는 양 | 분해됨 |
|---:|---:|:--|
| 20Hz | 6.64dB | 아니오 |
| 31.5Hz | 5.05dB | 아니오 |
| 50Hz | 3.32dB | 아니오 |
| 63Hz | 2.49dB | 아니오 |
| 80Hz | 1.78dB | 아니오 |
| 100Hz | 1.02dB | 아니오 |
| 125Hz | 0.92dB | 예 |
| 200Hz | 0.41dB | 예 |
| 1kHz | 0.00dB | 예 |

**예전 기준이 왜 틀렸는가** — 「밴드가 FFT 칸 폭보다 넓은가」로 판정했다.
63Hz 밴드의 폭(14.6Hz)은 칸 폭(11.7Hz)보다 넓어서 「충분히 분해됨」으로
통과했지만, 실제로는 2dB 넘게 빠진다. **폭은 창의 주파수 응답을 말해 주지
않는다.**

**새 기준**: 엔진을 만들 때 밴드마다 순음을 넣어 실제로 얼마나 빠지는지
재고, **1dB**(`LEAKAGE_TOLERANCE_DB`)을 넘으면 분해되지 않았다고 본다.
1dB 은 규격에서 온 값이 아니라 우리가 정한 선이다 — 귀로는 겨우 알아챌까
말까 하지만, 저역 균형을 보고 EQ 를 만지는 자리에서는 방향을 바꿀 만한
양이라 거기서 끊었다.

**어디에 적는가**: RTA 화면이 흐린 막대 아래에 「최대 N dB 낮게 나옵니다」를
실제 수치로 적는다.

**재지 않고 식으로 어림하지 않는 까닭**: 창·칸 나누기·경계 처리가 모두 섞인
결과라, 어림하면 어디서 틀렸는지 알 수 없다. 재는 데 FFT 93회가 드는데
(FFT 길이·샘플레이트 조합마다 한 번, 약 60ms) 결과를 기억해 두므로 두 번째
측정부터는 공짜다.

## 고치지 않고 두는 것의 조건

둘 다 **나중에 고칠 수 있는 길이 열려 있다**:

- 주파수 보정: 역응답 FIR/IIR 을 넣으면 광대역에도 걸 수 있다.
- 저역 분해: FFT 를 16384 로 키우면 100Hz 까지 1dB 안에 든다(창 341ms).
  반응이 느려지므로 하울링을 잡는 목적과 맞바꿔야 한다 — 값을 정하기 전에
  실제 예배당에서 재 본다.

그때까지는 **크기를 적고 화면이 알린다.** 「작다」고 말하지 않는다.

## 이 결정이 말하지 않는 것

- 이 앱이나 폰+마이크 전체가 IEC 61672 Class 1/2 라는 뜻이 아니다.
- 위 수치는 4096점·48kHz 기준이다. 샘플레이트가 다르면 다시 재야 한다
  (코드는 조합마다 다시 잰다).

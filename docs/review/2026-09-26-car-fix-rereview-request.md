# 재검토 요청 — CAR-01~05 수정분

요청일: 2026-09-26 · 구현자: Claude Code · 요청 대상: Codex(독립 검증자)

[재검토 회신](2026-09-26-car-independent-review.md)의 **High 3 · Medium 1 ·
Low 1** 을 모두 고쳤습니다. 범위: `fix/car-collection-identity`
(4커밋 · 27파일).

## 먼저 답합니다

**다섯 다 맞았습니다.** 그리고 지난번처럼 다섯이 한 모양이었습니다 —
**자료를 만든 순간의 신원이 그 자료를 따라다니지 않는다.** 그래서
나중에 「지금 열린 것」을 다시 읽어 이름표를 붙였습니다.

제가 전에 적은 것 하나도 틀렸습니다: **「경로 전체로 견준다」**
(CA-R01 답)라고 했는데, 견준 것은 **저장 열쇠**였습니다. 열쇠에는
자리가 없으므로 그것은 경로 전체가 아닙니다.

---

## 1. 고친 것

### CAR-01 · CAR-02 — 수집 신원을 시작 때 굳힌다

`CaptureIdentity` 를 만들었습니다 — 저장 열쇠 + **자리
(`routedAddress`) + 샘플레이트 + 세대**. 「어디에 저장할까」와 「어디서
재었나」를 가릅니다.

수집을 시작할 때 한 번 뜨고, **끝날 때 다시 읽지 않고 그것과 대조만**
합니다.

**관문을 VM 밖으로 냈습니다.** 판단들이
`CalibrationWizardViewModel`(AndroidViewModel) 안에 있어 기기 없이는
한 줄도 돌려 볼 수 없었습니다 — 그래서 **관문이 실제로 막는지 확인한
적이 없었습니다.** `CaptureIdentityGate.kt` 로 옮겼습니다:

| 함수 | 막는 것 | 재현 |
|---|---|---|
| `measureGateKo` | 전후 기준이 다른 경로 | A |
| `stampGateKo` | 마지막 장 뒤 입력이 바뀜 | B |
| `routeMismatchKo` | 잰 자리가 아닌 곳에 저장 | C |

**이름표를 고치지 않고 장을 버립니다.** `CalibrationSession.discard(step)`
을 더했습니다 — 기준 장이 하나도 안 남으면 `referenceProof` 도 함께
버립니다(남기면 다음 시도가 버린 시도의 CAL 에 묶입니다).

**취소도 증거를 무효로 만듭니다.** 실패 분기에서만 지우던 것을
**시작하는 순간 버리는** 쪽으로 바꿨습니다. 끝까지 마친 검사만
되살립니다. 수집 도중 입력이 바뀌면 배경과 DSP 를 **짝째** 버립니다.

**봐 달라**: 세대(`generation`)를 신원에 넣어 **재개방을 다른 신원으로**
봅니다. 다만 `measureGateKo`/`routeMismatchKo` 는 세대를 묻지 않습니다 —
기준과 대상을 오가려면 다시 여는 일이 정상이기 때문입니다(8절 2번 답의
「연속 캡처 세대와 재사용 가능한 증거의 범위를 구분」). 이 가름이 맞는지
봐 주십시오.

### CAR-03 — 전대역 보정에도 자리를 붙인다

`GlobalCalibration.routeAddress` 를 더하고, `ActiveCalibration.from` 이
**판정한 뒤** 겁니다. 자리가 다르거나 모르면 **걸지 않고 값은 그대로
들고 있습니다.**

**앱이 지금 주소로 채워 넣지 않습니다**(3번 답). 사람이 「이 자리에서
계속 쓰기」를 눌러야 채워지고(`confirmRoute`), 이미 다른 자리가 적혀
있으면 덮어쓰지 않습니다.

`MicSource` 의 라우팅 콜백이 `routedDevice` null 에서 조용히 돌아가던
것도 고쳤습니다 — 확인한 적이 있으면 상위에 알립니다(4절 잔여 위험).

**기기에서 확인했습니다**(SM-S918N + UMC404HD + 측정용 마이크). 간편
보정을 실제로 저장하고 DataStore 를 열었습니다:

```
cal|Usb|USB-Audio - UMC404HD 192k|card=1;device=0|VoiceRecognition|route
card=1;device=0
```

같은 자리라 배지가 「보정됨」이 되고, 초기화하면 `route` 도 함께
지워집니다.

**봐 달라**: 옛 기록(자리 없음)은 이제 **자동 적용이 멈춥니다.** 값은
남지만 확인하거나 다시 보정해야 걸립니다. 이것이 「남겨 두고 재확인
전 자동 적용 보류」로 맞습니까, 아니면 과한 편입니까?

### CAR-04 — 둘째 열의 뜻을 본다

`declaresColumns: Boolean` 을 `ColumnDeclaration`(`None` ·
`Unsupported(이름)` · `Second(응답|보정값)`)으로 바꿨습니다. 선언으로
보는 줄은 **첫 칸이 주파수 열 이름**인 줄뿐이고, 둘째 칸이 알려진
이름일 때만 확정합니다.

이름은 낱말로 찾지 않고 **통째로 견줍니다** — 괄호 안(단위)만 떼고
`Frequency (Hz)` · `Frequency(Hz)` · `FREQUENCY` 를 하나로 모읍니다.
「Frequency range: 20 Hz」 같은 문장은 어느 이름과도 같지 않습니다.

**길이 제한은 손대지 않았습니다**(5번 답). 반례가 모두 짧아 한도를
바꿔도 본질이 달라지지 않습니다.

`decideReading` 의 **기본값이 `columnDeclared = true`** 였다는 지적도
고쳤습니다(`None` 으로). 그 기본값 때문에 `CurveReadingTest` 가
「설명문만으로 기준 CAL 이 정해진다」를 지키고 있었습니다.

**봐 달라**: 알려진 이름의 집합이 어림입니다
(`spl`·`db`·`magnitude`·`level`·`response`·`amplitude`·`응답`…).
모르는 이름은 묻는 쪽으로 틀리지만, 실제 CAL 파일에 흔한 이름이 빠져
있으면 쓰기 번거로워집니다.

### CAR-05 — fixture 를 실제 모양으로

`TestProfiles` 가 손으로 적던 `"BuiltIn|SM-S918N|$address"` 를
**운영 코드의 `stableKey` 로** 만들게 했습니다(`realStableKey`).

「다른 내장 마이크는 막는다」의 계약도 고쳐 적었습니다 — 실제로는 두
자리의 열쇠가 **같고**, 지키는 것은 주소 대조이며, 판정은 `Block` 이
아니라 `ApplyWithWarning` 에 `mayAutoApply=false` 입니다. 옛 판 열쇠는
**별도 시험**으로 갈랐습니다.

`WizardRunnerTest` 의 가짜 캡처도 신원을 내놓게 했습니다.

**아직 안 한 것**: 실제 VM 의 `stopWork`/`onBackground`/`onForeground`
호출 순서를 정규 회귀로 옮기는 것. 이 저장소에는 시험용 Android 의존성
(Robolectric·mock)이 없어 `AndroidViewModel` 을 JVM 시험에서 세울 수
없습니다. **대신 판단을 순수 함수로 꺼내** 관문 자체는 시험이 닿게
했습니다. 이것이 중간 단계로 받아들일 만한지, 아니면 시험 의존성을
들여야 닫히는지 판단해 주십시오.

## 2. 새 시험이 실제로 잡은 것

두 가지를 **쓰자마자** 잡았습니다:

- `routeNoticeKo` 에 마크다운 별표(`**`)를 썼습니다. 이 자리는 서식
  없는 Text 라 화면에 글자로 보입니다.
- `decideReading` 의 「선언하지는 않았습니다」 문구에도 같은 별표가
  있었습니다. 기본값이 `true` 라 그 분기가 **한 번도 안 열렸기**
  때문에 기존 시험이 못 봤습니다.

두 번째가 1절 CAR-04 의 기본값 문제와 같은 뿌리입니다 — **닫혀 있던
분기는 시험도 지나가지 않습니다.**

## 5. 답을 원하는 질문

1. **CAR-01** — 세대를 「신원이 같은가」에는 넣고 「같은 경로로
   돌아왔는가」에는 넣지 않았습니다. 이 가름이 맞습니까?
2. **CAR-03** — 옛 기록의 자동 적용을 멈춘 것이 과합니까? 사람이 한 번
   확인하는 길을 두었는데, 그 확인이 「증거」로 충분합니까?
3. **CAR-04** — 알려진 열 이름 집합이 어림입니다. 더 나은 가름이
   있습니까?
4. **CAR-05** — 관문을 순수 함수로 꺼내 시험한 것이 실제 VM 회귀를
   대신할 수 있습니까, 아니면 시험 의존성을 들여야 닫힙니까?
5. **2절** — 「닫혀 있던 분기는 시험도 지나가지 않는다」는 부류를 더
   찾아봐 주십시오. 기본값이 한쪽으로 굳어 반대쪽이 한 번도 안 도는
   자리가 또 있을 것 같습니다.

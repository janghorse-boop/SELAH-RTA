## 지적이 정확합니다

「놓기를 시도하기 전에 먼저 등록한다」까지는 했는데, **`current` 에서 빠진
직후 등록되기 전의 짧은 구간**이 남아 있었습니다. 그 사이에 새 재생이
끼어들면 그 재생을 **`current` 에서도 pending 에서도 보지 못해** 상한을
넘겨 엽니다.

**목록 자물쇠는 멀쩡했습니다** — 문제는 말씀하신 그대로 **목록과 `current`
사이의 이전이 따로 일어난 것**이었습니다.

| | 검증자 | 제 이식 시험 |
|---|---|---|
| 재현 | 22번째 시도 · 열림 3 · pending 3 | **93번째 시도** · 열림 3 · pending 3 |

## 수정 — 한 임계구역 안에서 넘긴다

```kotlin
val mine = synchronized(lock) {
    val isCurrent = current === pb
    if (isCurrent) {
        current = null
        playing = null
    }
    stuck.addIfPending(pb) { it.isSlotFree }
    isCurrent
}
pb.releaseOnce()
if (pb.isSlotFree) stuck.remove(pb)
```

`stop()` 도 같은 규칙으로 바꿨습니다 — 떼어 내는 블록 **안에서** 등록하고,
`release`·`stopSink`·`join` 은 전부 **밖에서** 합니다. 잠금 안에는 등록과
상태 갱신만 둡니다.

그래서 재시작이 어느 순서로 끼어들어도 그 재생을 놓치지 않습니다:

- 오류 종료가 먼저 자물쇠를 잡으면 → `current` 도 비우고 등록도 끝난 뒤에
  `start()` 의 `stop()` 이 들어옵니다. 정리(sweep)가 그것을 봅니다.
- `start()` 의 `stop()` 이 먼저 잡으면 → 그쪽이 떼어 내며 등록합니다.
  뒤이은 오류 종료는 `current !== pb` 를 보고 알림만 건너뜁니다.

## 시험 — 무엇인지 있는 그대로

검증자 `AutoEndGapProbe.kt` 의 순서를 그대로 옮겼습니다(`playing` 이 비는
순간을 busy-wait 로 노려 바로 다음 재생을 시작).

**이것은 barrier 로 고정한 시험이 아니라 관찰 시험입니다.** 고친 뒤에는
그 구간 자체가 없어 barrier 를 놓을 자리가 없습니다. 그래서:

| | 결과 |
|---|---|
| 고치기 전 | **93번째 시도에 재현**(열림 3 · pending 3) |
| 고친 뒤 400회 | 위반 0 |
| 5회 연속 실행(누적 **2000회**) | 위반 0 |

「반복 통과가 증명이 아니다」라는 말씀을 그대로 적어 둡니다 — 이 시험이
보장하는 것은 **그 순서를 2000번 노려도 재현되지 않았다**는 것까지입니다.

## 답변에 대해

**1. `settle` 로 종료 규칙이 하나가 됐는가** — 「현재 상태에서 종료
추적으로 넘어가는 순간까지 묶인 것은 아니다」가 맞았고, 이번에 그 순간을
묶었습니다.

말씀하신 **`start()` 의 `open` 실패 뒤 `s.release()`** 는 아직 `settle`
밖입니다(Playback 이 만들어지기 전이라 붙일 자리가 없습니다). 「모든 자원
정리가 settle 로 통합됐다」고 넓혀 적지 않겠습니다. 실제 adapter 초기화
실패 시험은 미검증 목록에 두었습니다.

**2. 목록에 넣었다 빼는 비용** — 최적화를 위해 등록을 생략하지 않겠습니다.
「측정상 무시 가능」이라고 쓰지도 않겠습니다 — 재지 않았습니다.
`release`·`stop`·`join` 을 목록 자물쇠 밖에 두는 원칙은 유지합니다.

**3. 실기기 보고** — 「구현자 보고이며 독립 재실행하지 않았다」는 구분이
맞습니다. 트랙 수가 유지되고 오류 로그가 없다는 것이 **청감상 연속이나
출력 파형 무결성을 입증하지 않는다**는 점도 그대로 받습니다. 제가
확인한 것은 그 두 가지뿐입니다.

## 판단을 구하는 곳

1. **잠금 중첩.** `lock` 을 쥔 채 `PendingList` 의 자물쇠를 잡습니다.
   반대 방향(목록 자물쇠를 쥔 채 `lock`)은 없어서 고리가 생기지 않는다고
   봤는데, 그 판단이 맞는지.
2. **관찰 시험으로 남겨 둔 것.** 그 구간을 없앤 뒤에는 barrier 를 놓을
   자리가 없어 2000회 관찰로 갈음했습니다. 상태 이전 경계를 더 작게
   떼어 내 barrier 를 놓는 편이 나은지.

# SELAH RTA: Galaxy S23 Ultra 내장 마이크별 자동 교정 개발지시서

## 목적

기존 UMC404HD + EMM-6 USB 입력 기능을 기준 측정 경로로 사용하여 Galaxy S23 Ultra의 후면 및 하단 내장 마이크를 **실제로 독립 식별·선택할 수 있는 범위에서만** 각각 주파수 응답 교정한다. 마이크별 Calibration Profile을 생성, 저장, 적용한다. 물리 마이크를 구분할 수 없으면 `후면/하단` 프로파일을 추정하여 만들지 않는다.

## 1. 마이크 탐색과 식별

- `RECORD_AUDIO` 권한 획득 후 `AudioManager.getDevices(GET_DEVICES_INPUTS)` 및 `getMicrophones()`로 입력 장치와 마이크 ID, 위치, 그룹, 연결 장치 정보를 수집한다. 기기 모델명만으로 후면/하단 ID를 하드코딩하지 않는다.
- 후보별 `AudioRecord`를 실제 시작한다. 가능한 경우 `setPreferredDevice()`와 마이크 방향 설정을 시도하되, 이들의 성공 반환값을 실제 물리 마이크 선택의 증거로 삼지 않는다. 녹음 중 `getRoutedDevice()`, `getActiveMicrophones()`, 채널 매핑을 확인한다.
- 후면/하단 입구에서 통제된 근접 신호 또는 가림 테스트를 수행하여 API 정보와 음향 결과가 일치하는지 확인한다. 한 스트림에서 마이크가 혼합되거나 자동 전환되면 물리 마이크 프로파일로 취급하지 않는다.
- 결과를 `물리 마이크 독립 선택·식별 가능 / 논리 경로만 구분 가능 / 구분 불가`로 구분한다. 첫 경우에만 후면과 하단의 개별 교정을 허용한다. 나머지는 확인된 경로로만 명명하거나 개별 교정을 비활성화한다.
- USB 연결·해제, 녹음 재시작, 앱 재시작 후 실제 활성 마이크·채널·경로의 재현성을 검증한다.

## 2. 기준 장비 및 신호 점검

- EMM-6를 UMC404HD의 선택된 입력 채널에 연결한다. +48V 팬텀전원은 UMC404HD의 하드웨어 스위치를 사용자가 켜도록 안내한다. 앱은 상태를 제어하거나 켜짐을 확정하지 않고 실제 신호, 노이즈, 클리핑을 확인한다.
- EMM-6 개별 CAL 파일을 불러와 파일 형식, 주파수 범위, 보간 및 보정 부호를 검증하고 기준 응답에 적용한다. CAL 파일 식별자와 적용 상태를 보존한다.
- Android `UNPROCESSED` 지원 여부를 확인하고 가능하면 사용한다. 미지원 시 `VOICE_RECOGNITION` 등 후보를 실측 평가한다. AGC, NS, AEC의 가용성·활성화 상태를 확인하고 가능한 경우 비활성화한다. 설정값뿐 아니라 일정 레벨 신호의 시간별 이득·스펙트럼 변화와 반복성으로 잔여 DSP를 검증한다. 우회가 검증되지 않으면 교정을 중단하거나 제한적 정확도를 명시하고 자동 적용을 차단한다.
- 두 경로의 실제 sample rate, 채널 구성, 입력 소스, 라우팅, 레벨, SNR, 클리핑을 기록한다. 경로 변경 또는 신호 이상 시 측정을 중단한다.

## 3. 측정과 보정 계산

1. 조용한 환경에서 고정된 외부 스피커로 핑크 노이즈 또는 로그 스윕을 출력한다. 스피커 위치·레벨·휴대전화 자세를 고정한다.
2. EMM-6 캡슐과 대상 내장 마이크 입구가 가능한 한 같은 공간점을 향하도록 지그/위치 표시를 사용한다. 정확한 동위치 동시측정은 불가능하므로 `EMM-6 기준 → 내장 마이크 → EMM-6 재측정` 순서를 기본으로 한다. 기준 재측정 편차가 허용치를 넘으면 재시도한다.
3. 후면과 하단을 각각 독립 세션으로 반복 측정한다. 로그 스윕은 시간 정렬·디컨볼루션, 핑크 노이즈는 충분한 평균과 동일 FFT 설정을 적용한다. SNR이 낮거나 불안정한 구간을 배제한다.
4. EMM-6 개별 CAL을 적용한 기준 응답과 내장 마이크 응답을 공통 로그 주파수 축에 보간한다. 신뢰 가능한 중역 대역에서 전체 레벨을 정규화한 뒤 `correction_dB(f) = reference_dB(f) - internal_dB(f)`를 계산한다. fractional-octave smoothing을 적용하고 과도한 보정, 좁은 딥, 범위 밖 주파수는 제한/무효화한다. 정규화 대역, smoothing 폭, 보정 상한, 유효 주파수 범위를 저장한다.
5. 보정은 지정된 RTA 분석 단계에서 한 번만 적용한다. 원시 데이터와 정규화 전 측정 레벨을 별도로 보존한다.

## 4. 필수 비교 화면과 신뢰도 표시

교정 마법사의 결과 검토 단계와 저장된 프로파일 상세 화면에 다음을 **동일 세션 기준으로 나란히 또는 겹쳐** 표시한다.

- **볼륨 레벨 비교:** EMM-6 기준 입력과 대상 내장 마이크의 시간별 RMS 및 Peak, 클리핑 여부, 노이즈 플로어를 같은 시간축에 표시한다. 정규화 전 입력 레벨 차이(dB), 적용한 정규화 오프셋(dB), 정규화 기준 대역을 수치로 보여준다. 입력 경로의 이득 차이가 있으므로 이 값은 절대 음압 차이라고 표시하지 않는다.
- **주파수 응답 비교:** EMM-6 CAL 적용 기준 곡선, 내장 마이크 원시 곡선, 레벨 정규화한 내장 마이크 곡선, 보정 적용 후 곡선을 구분되는 색/범례로 같은 로그 주파수 그래프에 표시한다. 사용자가 원시/정규화/보정 후 곡선을 각각 켜고 끌 수 있게 한다. 같은 분석 설정·smoothing·주파수 축·dB 축을 사용한다.
- **보정치 확인:** 별도 그래프 또는 보조 축에 주파수별 correction dB 곡선을 표시한다. 특정 주파수를 선택하면 기준값, 원시값, 정규화값, 보정치, 보정 후 값과 해당 구간의 신뢰 상태를 보여준다.
- **측정 신뢰도:** 반복 측정 편차, EMM-6 전후 기준 측정 편차, SNR, 클리핑, DSP 검증 결과, 저신뢰/보정 제외 구간을 그래프 위에 표시한다. 허용 기준을 통과하지 못하면 저장·자동 적용을 막고 재측정을 안내한다.
- 기준/대상 측정이 순차적이고 마이크 위치가 완전히 같지 않다는 한계를 화면에 간결히 안내한다. 그래프와 수치가 갱신되어 사용자가 확인한 뒤 프로파일 저장을 승인할 수 있어야 한다.

## 5. 주파수 응답과 절대 SPL의 분리

본 기능은 상대 주파수 응답 보정이다. 위의 RMS/Peak와 정규화 전 레벨은 디지털 입력 레벨 및 상대 비교로 표시하며, 음압 캘리브레이터를 통한 별도 절차 없이는 정확한 dB SPL로 표시하지 않는다. 절대 SPL 보정 상태와 값은 별도 관리한다.

## 6. 프로파일 및 UI

각 프로파일에 UUID, 생성/수정 시각, 스키마·알고리즘 버전, 제조사·모델·Android/One UI 빌드, 확인된 마이크 ID·위치·그룹·채널 매핑, 입력 장치·라우팅·소스·sample rate, DSP 검사 결과, UMC404HD 입력 채널, EMM-6 CAL 파일 식별자/해시, 원시·정규화·보정 후 곡선, correction 곡선, 레벨 오프셋, smoothing·유효 범위·품질 지표를 저장한다.

앱 재시작 및 녹음 시작 시 실제 활성 마이크·채널·경로·sample rate를 다시 대조한다. 불일치하면 자동 적용하지 않고 이유를 표시한다. 후면/하단 프로파일은 서로 덮어쓰지 않는다. 프로파일 목록에서 비교 그래프, ON/OFF, 재검증, 재교정, 삭제를 제공한다. RTA 화면에는 현재 적용 중인 프로파일과 마이크/경로를 표시한다. OS 업데이트, 경로 변화, 반복성 저하, 케이스 등 음향 조건 변경 시 재검증을 요청한다.

교정 마법사는 `장비/CAL/+48V 안내 → 입력·DSP 점검 → 물리 마이크 판정 → 기준/대상/기준 측정 → 레벨·응답·보정치 비교 → 저장` 순서로 구현한다.

## 7. 테스트 및 Definition of Done

1. Galaxy S23 Ultra 실기기에서 Android/One UI 빌드별 마이크 목록, 활성 마이크, 채널 매핑 및 물리 마이크 독립 선택 가능 여부를 기록한다. 구분 불가 시 개별 프로파일 생성이 차단된다.
2. 구분 가능한 환경에서 후면/하단 프로파일의 독립 생성, 저장, 재시작 후 재적용, ON/OFF, 삭제를 검증한다. 경로 변경 시 잘못된 프로파일 적용을 차단한다.
3. 알려진 합성 응답으로 EMM-6 CAL 적용, 보정 부호, 로그 주파수 보간, 레벨 정규화, smoothing, 보정 상한, 한 번만 적용되는 처리 순서를 검증한다.
4. 비교 화면의 RMS/Peak·레벨 차이·정규화 오프셋·네 가지 응답 곡선·correction 곡선이 저장된 측정 데이터와 일치한다. 그래프에서 특정 주파수의 수치를 조회할 수 있다.
5. 실기기 반복 측정과 별도 재측정으로 보정 전후 오차, 기준 재측정 편차, SNR을 비교한다. 허용 오차와 주파수 범위를 사전 정의하고 전후 그래프와 결과를 보고한다.
6. AGC/NS/AEC 우회 불가, USB 분리, 무신호, 클리핑, CAL 오류, 권한 거부, 스피커 출력 변화, OS 업데이트 후 경로 변화에서 적절한 안내·재시도·안전한 비활성화를 검증한다.
7. 완료 보고서에 구현 파일, 기기/OS 버전, 실제 지원되는 선택 범위, 비교 화면 캡처, 측정 데이터, 전후 그래프, 알려진 한계와 재교정 조건을 포함한다.

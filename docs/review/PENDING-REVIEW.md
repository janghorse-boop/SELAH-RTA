## 4. 악기 EQ 가이드 화면 개편

| | |
|---|---|
| 요청서 | 없음 — **이 문서가 전부다** |
| 지시서 | 담당자 2026-09-30 「악기 EQ 가이드 화면 개편 개발지시서」 |

**무엇을 했나**: 이 화면을 **실습형**으로 바꿨다. 게이트·컴프레서 탭,
「무엇을 볼까요」, 「전부 보기/증상만」을 **화면에서** 뺐다(카탈로그 자료는
그대로 둔다 — 명세 §15 가 요구한다). 위에 **RTA 를 붙박고**, 아래 카드를
고르면 그 대역이 그림에서 **띠로 강조**된다.

**봐 달라**:
- **대역 ↔ 밴드 짝짓기**(`EqBandHighlight`). 80~150 Hz 가 80·100·125·**160**
  이다 — 160 칸의 아래끝이 141.3 Hz 라 겹친다. 이 경계 규칙이 맞는가.
- **말이 처방으로 새지 않는가.** 「올려라·내려라」를 화면에서 찾는 시험을
  걸어 두었지만, 그것으로 충분한지.
- **카드의 「많을 때」를 기존 증상 태그로 채운 것**(담당자 확인). 없던
  문장을 새로 짓지 않으려는 선택인데, 그 대신 「적을 때」가 없다.

**확인한 것**: 실기기(SM-S918N)에서 계측 66개 같은 결과이고, 화면도
찍어서 봤다 — 측정이 꺼진 자리, 켜 뒤의 띄, 카드를 바꾸면 띄가
150~350 Hz 로 **따라 움직이는 것**까지. 밝은 테마에서도 띄가 막대와
갈린다.

**확인 못 한 것**: **실제 악기·믹서로 돌려 보는 것**(지시서 §36 의 6~9번).
그것은 사람이 예배당에서 해야 한다.

## 5. 곁다리로 고친 것 — 보던 화면을 잃는 문제

악기 EQ 를 기기에서 보다가 찾았다. `SelahApp` 의 **구역·칩이 `remember`**
였다 — 화면이 다시 만들어지면 값을 잃고 **측정 탭으로 돌아간다.**

개발자 옵션 「활동 유지 안 함」을 켜고 홈으로 나갔다 돌아오면, 옛 판은
측정 화면으로 · 고친 판은 보던 화면으로 온다(둘 다 확인). 마법사·프로필
여닫이는 이미 `rememberSaveable` 이었고 **자리만 빠져 있었다.**

> **처음에는 까닭을 잘못 짚었다.** 「권한 대화상자 때문」이라고 적었는데,
> 실은 **제 시험 좌표가 낡아** 엉뚱한 곳을 누른 것이었다. 고침 자체는
> 맞았지만 **그 까닭은 틀렸고**, 주석을 실제로 확인한 대로 고쳐 적었다.

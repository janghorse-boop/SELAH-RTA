# 저작권·플레이스토어 점검 (유료 구독을 전제로)

날짜: 2026-09-24
계기: 담당자 지시 — 「유료구독으로 운영할 거라 저작권에 문제가 없어야
하고, 플레이스토어 등록도 고려해 달라」

> **이 문서는 법률 자문이 아니다.** 저장소에 실제로 무엇이 들어 있는지
> 확인한 기술 점검이고, 판단이 필요한 자리는 그렇게 적었다.

## 1. 남의 것이 들어와 있는가 — **거의 없다**

### 라이브러리

앱과 dsp 모듈이 쓰는 것 전부:

| 것 | 라이선스 | 상용·유료 배포 |
|---|---|---|
| AndroidX core-ktx, datastore, lifecycle, activity-compose | Apache 2.0 | 됨 |
| Compose BOM, ui, ui-graphics, material3 | Apache 2.0 | 됨 |
| JUnit 4 | EPL 1.0 | **시험 전용 — 앱에 안 실림** |

**GPL·AGPL·상용 제한 라이브러리가 하나도 없다.** DSP(FFT·필터·밴드 분석)는
이 저장소에서 직접 쓴 코드다 — 남의 DSP 라이브러리를 가져오지 않았다.

Apache 2.0 는 유료 배포를 허용하지만 **고지 의무**가 있다. 앱 정보 화면에
오픈소스 고지를 한 줄 넣어야 한다(아래 3장 할 일).

### 글꼴·그림

- **번들 글꼴 없음** — 시스템 글꼴을 쓴다. 글꼴은 유료화에서 가장 자주
  걸리는 자리인데, 여기서는 걸릴 것이 없다.
- 그림은 벡터 XML 넷(`ic_nav_*`)과 런처 아이콘뿐이다. 모양이 구글
  **Material Symbols**(Apache 2.0)에서 온 것으로 보인다 — 상용 배포에
  문제 없다. **출처를 기록해 둔다**(아래 할 일).
- 사진·음원·폰트 파일 등 **가져다 쓴 자산이 없다.**

### 남의 상표

앱 화면에 뜨는 타사 이름은 **한 곳뿐**이다:

> `CurveCard` — 「예: Dayton EMM-6 #123456 · iMM-6C #123456」

지원하는 마이크를 가리키는 **지명(指名)적 사용**이라 일반적으로 문제되지
않는 형태다. 다만 지킬 것:

- 스토어 등록 문구와 아이콘에 **타사 상표를 쓰지 않는다**
- **「Smaart」는 앱에도 스토어 문구에도 쓰지 않는다.** 가격 전략 문서에만
  경쟁 비교로 적혀 있고, 그 문서는 내부 자료다. 비교 광고는 상표 분쟁의
  단골이다
- 「SELAH RTA」가 남의 상표와 겹치지 않는지 **출시 전 확인**(판단 필요)

## 2. 개인정보 — **수집하는 것이 없다**

| 확인한 것 | 결과 |
|---|---|
| 권한 | RECORD_AUDIO · FOREGROUND_SERVICE(+MICROPHONE) · POST_NOTIFICATIONS |
| **INTERNET 권한** | **없음** |
| 네트워크 코드 | 없음(HTTP·소켓·URL 사용 없음) |
| 저장하는 것 | 설정·보정 프로파일(DataStore, 기기 안) |
| 소리 저장 | **하지 않음** — 음압·주파수만 계산 |

**인터넷 권한이 없다는 것이 이 앱의 가장 큰 자산이다.** 밖으로 나가는 길이
없으므로 데이터 안전 항목이 「수집 없음」으로 단순해진다.

마이크 권한 화면에 이미 이렇게 적고 있다 — 「이 앱은 소리를 저장하지 않고
음압과 주파수만 계산합니다」. 구글이 요구하는 **프로미넌트 디스클로저**에
해당한다.

> **구독을 붙이면 이 그림이 바뀐다.** 결제는 Play Billing 이 처리하므로 앱이
> 결제정보를 만지지는 않지만, 구독 상태 확인에 네트워크가 필요할 수 있다.
> 그때 데이터 안전 항목을 다시 쓴다.

## 3. 플레이스토어 — 이미 된 것과 남은 것

### 이미 맞춰 둔 것

- `targetSdk 36` / `compileSdk 36` — 현재 요구 수준
- `minSdk 26`
- **`foregroundServiceType="microphone"`** 선언 — 안드로이드 14+ 필수
- `FOREGROUND_SERVICE_MICROPHONE` 권한
- 마이크 사용 이유를 앱 안에서 먼저 설명

### 남은 것

| 할 일 | 왜 | 누가 |
|---|---|---|
| **개인정보처리방침 URL** | 마이크 쓰는 앱은 **필수**. 없으면 등록 자체가 안 된다 | 문안은 Claude 가 초안, 게시는 담당자 |
| **데이터 안전 양식** | 「수집 없음」으로 간단하지만 제출은 해야 함 | 담당자 |
| 오픈소스 고지(앱 정보 화면) | Apache 2.0 고지 의무 | Claude |
| 그림 출처 기록 | 나중에 「이거 어디서 왔지」가 안 되게 | Claude |
| **릴리스 서명 키** | `app/build.gradle.kts` 에 `release` 블록은 있으나 서명 설정 없음. 키스토어는 git 제외 | 담당자(키 보관) |
| versionCode·versionName | 지금 1 / 0.1.0. 출시 전 정리 | 담당자 결정 |
| 마이크 권한 **스토어 설명** | 스토어 문구에도 왜 필요한지 적어야 함 | 담당자 |
| **구독 상품 등록 + Play Billing** | 가격 확정 **뒤에** 한다(전략 문서 8장) | 나중 |

### 유료 구독일 때 추가로 보는 것

- **Play Billing 외의 결제 수단을 앱에 넣지 않는다** — 정책 위반
- 구독 해지 경로·첫 청구일·금액을 앱에서 확인할 수 있어야 한다
  (전략 문서 5장이 이미 요구)
- **미완성 기능을 스토어 설명에 적지 않는다**(전략 문서 8장). 전달함수·
  위상·코히어런스는 지금 없다
- 「공식 청력 안전기준」처럼 읽히는 문구를 스토어에 쓰지 않는다 —
  건강·의료 주장으로 분류되면 심사가 달라진다

## 4. 지금 판단이 필요한 것

1. **앱 이름 「SELAH RTA」의 상표 충돌** — 확인 필요
2. **개인정보처리방침을 어디에 게시할 것인가** — 회사 도메인 한 자리가
   필요하다(예: `svtone.seoulav.co.kr` 아래 또는 별도 페이지)
3. **판매 주체** — 개인 개발자 계정인지 법인 계정인지에 따라 세금·표시가
   달라진다(전략 문서 7장)

## 5. 결론

**지금 코드에는 저작권 문제가 될 만한 것이 들어 있지 않다.** 라이브러리는
전부 Apache 2.0, 번들 글꼴·가져온 자산 없음, 타사 상표는 지명적 사용 한 곳.

스토어 등록을 막는 것은 **개인정보처리방침 URL 하나**다. 나머지는 출시
시점에 맞추면 된다.

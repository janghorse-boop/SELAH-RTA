# USB-C 오디오인터페이스 — 꽂았을 때 무엇이 보여야 정상인가

폰에 인터페이스를 꽂고 **다섯 자리만** 보면 됩니다. 다섯 자리가 다
맞으면 그 인터페이스로 잴 수 있습니다. 한 자리가 틀리면 그 줄에 적힌
곳을 보십시오.

---

## 0. 먼저 알아 둘 것 — ASIO 는 안드로이드에 없습니다

ASIO 는 **윈도우 전용** 드라이버 규격입니다. 안드로이드에는 없고,
필요하지도 않습니다. 안드로이드는 **USB Audio Class(UAC)** 라는 표준을
쓰고, 이 표준을 따르는 인터페이스는 **드라이버 없이 꽂으면 그냥
됩니다.**

| | 윈도우 | 안드로이드 |
|---|---|---|
| 드라이버 | 제조사 ASIO 드라이버를 깐다 | **깔지 않는다** |
| 규격 | ASIO / WASAPI | USB Audio Class 1.0 / 2.0 |
| 설정 | 드라이버 제어판에서 고른다 | 앱의 **설정 → 입력 기기**에서 고른다 |

**살 때 볼 말**: 제품 설명에 **"class compliant"**(클래스 준수) 또는
**"no driver needed for iOS/Android"** 라고 적혀 있으면 됩니다.
반대로 **"requires driver"**(전용 드라이버 필요)만 적혀 있으면
안드로이드에서 안 됩니다 — 이것은 앱 설정으로 풀 수 있는 문제가
아닙니다.

흔히 쓰는 것 중 class compliant 인 것: Focusrite Scarlett,
Behringer UMC, Zoom, MOTU M 시리즈, RME, SSL 2.

---

## 1. 꽂기 전에 — 전원

**팬텀 전원(+48V)을 쓰는 인터페이스는 폰 배터리만으로 모자랄 수
있습니다.** 소리가 끊기거나 인식이 들락날락하면 거의 이것입니다.

- **전원이 따로 들어가는 USB-C 허브**를 쓰십시오(PD 충전 단자가 있는 것).
- 폰 → 허브 → 인터페이스 순으로 꽂고, 허브에 충전기를 물립니다.
- 인터페이스에 자체 전원 어댑터가 있으면 그것을 쓰는 편이 가장 안전합니다.

## 2. 다섯 자리 점검

측정을 시작한 뒤 **측정 화면을 아래로 내리면 「캡처 진단」**이 있습니다.
여기서 넷을 보고, 설정에서 하나를 봅니다.

### ① 입력 기기 — 인터페이스 이름이 뜨는가

> 설정 → **입력 기기**

꽂으면 목록에 인터페이스 이름이 나와야 합니다(예: `UMC404HD`).

| 보이는 것 | 뜻 |
|---|---|
| 인터페이스 이름이 있다 | **정상.** 눌러서 고르십시오 |
| 이름이 없다 | 아래 「안 보일 때」로 |

> 한 번 꽂았던 기기는 **빼도 목록에 남습니다.** 예배당에서 인터페이스를
> 늘 꽂아 두지 않으므로, 뺀 사이에 「그 기기로 고를 수 있다」는 사실
> 자체가 사라지지 않게 한 것입니다.

### ② 채널 — 몇 채널로 열렸는가

> 측정 화면 → 캡처 진단 → **채널**

4채널 인터페이스를 꽂아도 안드로이드가 **2채널만 열어 주는 일이
흔합니다.** 그래서 이 앱은 요청한 값이 아니라 **실제로 열린 값**을
적습니다.

| 보이는 것 | 뜻 |
|---|---|
| `4 중 1번` | 네 채널로 열렸고 **1번을 재고 있습니다** |
| `2 중 1번` | **Input 1·2 만** 열렸습니다. 마이크가 3·4번에 꽂혀 있으면 1이나 2로 옮기십시오 |
| `1 (모노)` | 한 채널로 열렸습니다 |

**「4 중 1번」의 뒷숫자가 마이크를 꽂은 입력 번호와 같아야 합니다.**
다르면 ③ 에서 고치십시오.

### ③ 측정 입력 채널 — 어느 입력으로 재는가

> 설정 → **측정 입력 채널**
> (여러 채널로 열린 기기에서만 나옵니다)

**섞지 않습니다.** 채널마다 다른 마이크가 꽂혀 있을 수 있어, 섞으면
어느 마이크의 소리를 재고 있는지 말할 수 없게 됩니다.

마이크를 꽂은 입력 번호를 고르십시오. **기기마다 따로 기억**하므로,
UMC404HD 의 Input 1 을 골라 두면 내장 마이크로 갔다 돌아와도 그대로
남아 있습니다.

**어느 입력에 마이크가 꽂혀 있는지 모르겠으면**, 바로 아래 **「입력마다
들어오는 소리」** 를 보십시오. 마이크에 대고 말하면 **움직이는 줄**이
그 입력입니다.

> ### 먼저 — **마지막 번호를 고르십시오**
>
> 앱은 **고른 번호가 들어가는 만큼만** 채널을 엽니다. 버스 대역과
> 버퍼를 아끼려는 것입니다. 그래서 **Input 1 을 고르면 한 채널만
> 열려**, 견줄 것이 없어 아래 막대가 **아예 뜨지 않습니다.**
>
> 찾을 때는 **가장 큰 번호**(4채널이면 Input 4)를 고르십시오. 그러면
> 모든 입력이 함께 열려 비교할 수 있습니다. **찾은 뒤 그 번호로
> 되돌리십시오** — 쓰지 않는 채널을 계속 열어 둘 까닭이 없습니다.
>
> 한 채널만 열려 있으면 앱이 이 안내를 화면에도 띄웁니다.

```
입력마다 들어오는 소리
마이크에 대고 말해 보십시오. 움직이는 줄이 마이크가 꽂힌 입력입니다.

Input 1  ████████░░░░░░░░   -18     ← 고른 채널은 색이 다릅니다
Input 2  ░░░░░░░░░░░░░░░░    —
Input 3  ██░░░░░░░░░░░░░░   -52
Input 4  ░░░░░░░░░░░░░░░░    —
```

| 보이는 것 | 뜻 |
|---|---|
| 말할 때 그 줄만 움직인다 | **그 입력입니다.** 위에서 그 번호를 고르십시오 |
| `—` | 아무것도 안 들어옵니다. **조용한 것이 아닙니다** |
| 여러 줄이 같이 움직인다 | 마이크가 여럿 꽂혀 있거나, 인터페이스가 입력을 섞고 있습니다 |

이 줄은 **음압이 아니라 신호 세기(dBFS)** 입니다. 보정을 걸지 않으므로
「어디에 꽂혀 있나」를 찾는 데만 쓰십시오.

### ④ 입력 레벨 — 소리가 들어오는가

> 측정 화면의 **「입력 레벨」** 줄
> (`Peak −18.2 dBFS · RMS −26.4 dBFS` 처럼 나옵니다)

마이크에 대고 말할 때 숫자가 움직여야 합니다. **이것은 음압이
아닙니다** — 마이크에 소리가 들어오는지만 봅니다.

| 보이는 것 | 무엇을 할까 |
|---|---|
| Peak 가 `−30 ~ −12 dBFS` 에서 움직인다 | **좋습니다** |
| 거의 안 움직인다(`−60` 아래) | 채널이 틀렸거나(③), 팬텀 전원이 꺼졌거나(콘덴서 마이크), GAIN 이 낮습니다 |
| **`잘림!`** 이 뜬다 | 인터페이스의 **GAIN 을 낮추십시오.** 앱에서는 못 낮춥니다 |

> **Peak 와 RMS 를 함께 적는 까닭**: Peak 만 보면 툭 튄 소리 하나로
> 「크다」고 읽히고, RMS 만 보면 잘리고 있는데도 「여유 있다」고
> 읽힙니다. **둘의 차이가 곧 헤드룸**입니다.

### ⑤ 샘플레이트·샘플 형식 — 제대로 열렸는가

> 측정 화면 → 캡처 진단 → **샘플레이트 / 샘플 형식**

`48000 Hz` · `32 bit float` 이면 정상입니다. 44100 이어도 괜찮습니다 —
앱이 **실제로 열린 값**으로 셈합니다.

## 3. 안 보일 때

순서대로 짚으십시오. 위에서부터 흔한 순입니다.

1. **전원.** 전원 들어가는 허브로 바꿔 꽂습니다(§1). 가장 흔합니다.
2. **케이블.** 충전 전용 케이블은 데이터가 안 갑니다. **데이터 케이블**로
   바꿉니다.
3. **인터페이스의 모드 스위치.** 어떤 제품은 뒤에 `Class Compliant` /
   `USB` 모드 스위치가 있습니다. 그쪽으로 놓습니다.
4. **폰이 물어본 권한.** 꽂을 때 안드로이드가 「이 앱에서 열까요?」를
   물으면 **허용**합니다. 「항상」에 체크해 두면 다음부터 안 묻습니다.
5. **다른 앱이 붙잡고 있는가.** 녹음 앱이나 통화 앱이 마이크를 쥐고
   있으면 이 앱이 못 엽니다. 그 앱을 끄고 다시 시작합니다.
6. **그래도 안 되면 class compliant 가 아닐 수 있습니다.** 제품 설명을
   다시 보십시오(§0).

## 4. 잰 뒤에 — 보정은 기기마다 따로입니다

**인터페이스로 잰 값은 폰 내장 마이크의 보정과 아무 상관이 없습니다.**
감도가 수십 dB 다르기 때문입니다. 그래서 이 앱은 **기기마다 보정값을
따로** 둡니다.

- 인터페이스를 꽂은 상태에서 **교정을 새로 하십시오**(설정 → 교정 마법사).
- 마이크 주파수 응답 파일(`.cal`·`.frd`·`.txt`)이 있으면
  설정 → **주파수 보정 (전문)** 에서 넣습니다. 이것도 기기마다 따로
  기억합니다.
- 교정 전까지는 「미보정」으로 뜨고, 숫자는 참고용입니다.

---

## 5. 팬텀 전원은 앱이 확인해 주지 못합니다

**앱은 +48V 가 켜졌는지 알 수 없습니다.** 신호가 들어온다는 것은 팬텀이
켜졌다는 증거가 아닙니다 — 다이내믹 마이크는 팬텀 없이도 소리를 냅니다.

그래서 앱은 확인한 것과 못 한 것을 갈라 적습니다. **팬텀은 사람이
인터페이스의 +48V 램프를 눈으로 봐야 합니다.**

EMM-6·iMM-6 같은 측정용 콘덴서 마이크는 팬텀이 **반드시** 필요합니다.
램프가 꺼져 있으면 레벨이 거의 안 움직입니다(④).

## 6. 한 장 요약

```
폰 ──(데이터 케이블)── 전원 허브 ──── 인터페이스 ──── 측정 마이크
                         ↑충전기              ↑+48V 램프 확인

설정 → 입력 기기        : 인터페이스 이름이 뜨는가
설정 → 측정 입력 채널   : (찾을 때) 먼저 **마지막 번호**로
설정 → 입력마다 들어오는 소리 : 말할 때 어느 줄이 움직이나
설정 → 측정 입력 채널   : 찾은 그 번호로 되돌리기
측정 → 입력 레벨        : 말할 때 Peak 가 -30~-12 dBFS 에서 움직이나
측정 → 캡처 진단
   채널                : 「4 중 1번」의 뒷숫자가 맞나
   샘플레이트/형식     : 48000 Hz · 32 bit float
설정 → 교정 마법사     : 이 기기로 새로 교정
```

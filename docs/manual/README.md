# SELAH RTA 사용 안내

교회 음향을 맡은 분들을 위한 안내입니다. **음향을 전공하지 않았어도**
읽을 수 있게 썼습니다.

> **현장에서 폰으로 보는 것을 가정합니다.** 필요한 곳만 펴 보십시오.

| 무엇이 궁금한가 | 어디로 |
|---|---|
| 처음 켰습니다 | [1. 시작하기](#1-시작하기) |
| 지금 얼마나 큰지 보고 싶습니다 | [2. 측정](#2-측정) |
| 어느 대역이 센지 보고 싶습니다 | [3. 분석](#3-분석) |
| 소리를 내보내 보고 싶습니다 | [4. 도구](#4-도구) |
| 숫자를 더 믿을 수 있게 만들고 싶습니다 | [5. 설정](#5-설정) · [6. 정확한 값](#6-정확한-값이-필요할-때) |
| 안 되는 게 있습니다 | [7. 이 앱이 하지 않는 것](#7-이-앱이-하지-않는-것) |

---

## 0. 먼저 알아 둘 두 가지

**하나. 이 앱은 법으로 정한 소음 측정을 대신하지 못합니다.**
소음 평가·작업환경측정처럼 장비와 자격이 정해진 판단에는 **그 요건을
갖춘 별도의 측정**이 필요합니다.

**둘. 보정하기 전의 숫자는 「참고용」입니다.**
화면에 늘 **보정 상태**가 적혀 있습니다. 「미보정」이면 그 dB 값은
실제 음압과 **10dB 넘게 다를 수 있습니다.** 숫자를 남에게 건넬 일이
있다면 [6장](#6-정확한-값이-필요할-때)을 먼저 보십시오.

## 1. 시작하기

### 아래 탭 다섯

| 탭 | 무엇을 하나 |
|---|---|
| **측정** | 지금 얼마나 큰가 (SPL) |
| **분석** | 어느 대역이 센가 (RTA·Spectrum·Spectrogram·FR) |
| **도구** | 소리를 내보낸다 (테스트 신호·악기 EQ) |
| **기록** | 지난 예배를 다시 본다 |
| **설정** | 입력 기기·보정·측정 설정 |

### 마이크 권한

처음 측정을 시작하면 마이크 권한을 묻습니다. **허락해야 잽니다.**

### 무엇을 저장하고, 무엇을 저장하지 않나

- **저장합니다**: 숫자(dB·대역별 값)와 그때의 측정 조건.
- **소리는 기본이 아닙니다.** 기록할 때 **「소리도 담기」를 골라야**
  담깁니다 — 예배 소리를 담는 일은 dB 숫자를 남기는 것과 성격이
  다릅니다(설교와 성도들의 목소리가 그대로 들어갑니다).
- **밖으로 보내지 않습니다.** 내보내기를 누를 때만 나갑니다.

## 2. 측정

> **이 화면이 답하는 것: 「지금 얼마나 큰가?」**

### 큰 숫자 읽는 법

가운데 큰 숫자가 **지금 값**입니다. 아래에 **Leq(구간)**·**MAX**·**PEAK**
이 함께 뜹니다.

| 말 | 뜻 |
|---|---|
| **지금 값** | 이 순간의 크기 |
| **Leq(구간)** | 정한 구간 동안의 **에너지 평균** |
| **MAX** | 그 구간에서 가장 컸던 **시간가중** 값 |
| **PEAK** | 파형이 순간적으로 튄 **가장 큰 값** |

### ⚠ 가장 잘못 읽히는 것

> **큰 숫자와 권장 범위는 같은 잣대가 아닙니다.**

권장 범위는 **Leq 기준**입니다. 큰 숫자가 잠깐 범위를 넘었다고 해서
「너무 크다」가 아닙니다. **범위를 볼 때는 Leq 를 보십시오.**

**PEAK 도 다른 잣대입니다** — 가중을 걸기 전의 값이라 dBA 눈금과 같은
자에 올릴 수 없습니다.

### 설교와 찬양

화면 안에서 구간을 고릅니다. 같은 화면이고 **권장 범위만 다릅니다.**

### 기록하기

예배를 통째로 남기려면 화면 아래 **「이 측정을 기록하기」**를 누릅니다.
멈출 때는 **「기록 중지」**입니다.

누르면 **「소리도 담을까요?」**를 한 번 묻습니다.

| 고른 것 | 남는 것 |
|---|---|
| 숫자만 | dB·대역별 값과 그때의 측정 조건 |
| **「소리도 담기」** | 위의 것 **+ 소리 파일** |

**소리를 담아 두면 나중에 다시 셈할 수 있습니다**(→ [6장](#6-정확한-값이-필요할-때)).
숫자만 남기면 그때의 보정으로 굳습니다.

## 3. 분석

### RTA — 31밴드

> **「지금 어느 대역이 센가?」**

가로가 주파수, 세로가 크기입니다. 막대가 높은 칸이 센 대역입니다.

**⚠ 차트의 표식은 「어디」만 가리킵니다.** 정확한 숫자는 **글자로**
읽으십시오 — 막대 높이를 눈대중으로 재지 마십시오.

### Spectrum — 칸 그대로 보기

> **「그 대역 안에서 정확히 몇 Hz 인가?」**

RTA 는 31칸으로 묶어 보여 주고, Spectrum 은 **묶지 않고** 보여 줍니다.

**⚠ 이 화면의 값어치는 그림이 아니라 봉우리 옆의 숫자**에 있습니다.
「1kHz 쯤」이 아니라 「1,012Hz」를 알아야 할 때 씁니다.

### Spectrogram — 시간으로 보기

> **「언제부터 올라왔나?」**

가로가 시간, 세로가 주파수입니다. 하울링이 **언제 시작됐는지** 볼 때
씁니다.

### FR — 방·PA 의 크기 응답

> **「이 방과 PA 가 주파수마다 어떻게 나오는가?」**

**⚠ 전달함수가 아닙니다.** 위상과 지연은 보지 않습니다. **크기만**
봅니다 — 그것만으로도 「저음이 뭉친다」는 알 수 있습니다.

### 피드백(하울링) 알림

특정 대역이 **계속 솟아 있으면** 후보로 표시합니다.

**⚠ 표시가 떴다고 반드시 하울링은 아닙니다.** 오르간이나 긴 노트도
비슷하게 보입니다. **귀로 함께 확인**하십시오.

---

## 4. 도구

### 테스트 신호

> **「이 방에 소리를 넣어 보려면?」**

핑크 노이즈·순음 등을 내보냅니다. 좌·우·양쪽을 고를 수 있습니다.

**⚠ 폰 스피커로 낸 소리는 측정의 기준이 되지 못합니다.**
폰 스피커는 저음이 거의 안 나옵니다. **PA 로 내보내십시오.**

### 악기 EQ 가이드

> **「이 악기의 이 대역을 만지면 소리가 어떻게 달라지나?」**

악기를 고르면 그 악기가 주로 사는 대역이 **위 RTA 에 띠로** 밝아집니다.

**⚠ 밝아진 띠는 「이 대역을 고치라」는 뜻이 아닙니다.** 「이 악기는
여기쯤에 있다」는 표시입니다. 무엇을 만질지는 **듣고** 정합니다.

---

## 5. 설정

> **「이 폰이 내는 숫자를 얼마나 믿을 수 있게 만들 것인가?」**

### ⚠ 「보정」과 「교정」은 다른 일입니다

| | 무엇을 하나 | 무엇이 필요한가 |
|---|---|---|
| **보정** | 전체 크기를 맞춘다 (1kHz 한 점) | 음압 교정기 또는 기준 소음계 |
| **교정** | 주파수마다 얼마나 더·덜 잡는지 **곡선**을 만든다 | 기준 마이크 |

**보정만 해도 절대 크기는 맞습니다.** 교정은 그 위에 「대역별 치우침」을
얹는 일입니다.

### 입력 기기

폰 내장 마이크와 USB 마이크를 고릅니다. **USB 는 꽂으면 목록에
뜹니다**(→ [USB 점검](usb-audio-interface-check.md)).

### 측정 설정

| 설정 | 어디에 걸리나 |
|---|---|
| **음압 가중** | 지금 값·Leq·MIN·MAX |
| **순간최고(PEAK) 가중** | PEAK |
| **주파수 분석 가중** | RTA·Spectrum·Spectrogram |

**셋은 따로입니다.** 하나를 바꿨다고 나머지가 따라가지 않습니다.

## 6. 정확한 값이 필요할 때

숫자를 **남에게 건넬** 일이 있으면 여기까지 하십시오.

### 어디까지 왔는지 화면이 늘 말해 줍니다

| 표시 | 뜻 |
|---|---|
| **보정 안 함** (짧게 「미보정」) | 참고용입니다. 실제와 10dB 넘게 다를 수 있습니다 |
| **기종 기본값** (짧게 「기본값」) | 같은 기종에서 잰 값을 실어 둔 것입니다. **이 기기를 잰 값은 아닙니다** |
| **전대역 보정** (짧게 「보정됨」) | 전체 크기를 맞췄습니다 |
| **주파수 보정** | 대역별 치우침까지 맞췄습니다 |

### ⚠ 맞춘 직후 화면이 기준값을 가리키는 것은 **당연합니다**

보정은 「기준값 − 지금 읽는 값」이라, **무엇에 대고 맞추든** 맞춘 직후
화면은 기준값을 가리킵니다. **틀릴수록 오히려 멀쩡해 보입니다.**

확인하는 길은 하나입니다 — **다른 레벨을 넣어 보십시오.**
94dB 로 맞췄다면 114dB 을 넣었을 때 **114 근처**가 나와야 합니다.

자세한 절차: **[음압 교정기(ND-9) 현장 절차](calibrator-nd9-check.md)**

### 보정을 나중에 해도 됩니다

예배 때는 미보정으로 담아 두고, 나중에 보정한 뒤
**기록 → 다시 분석**을 누르면 **그 소리를 새 잣대로 다시 셈합니다.**

**소리와 처음 잰 값은 그대로 남습니다.** 다시 분석한 기록에는
**「처음 잰 값으로 되돌리기」**가 함께 뜹니다 — 눌러 보면 원래대로
돌아옵니다. 되돌린 뒤에 **또 다시 분석해도** 됩니다.

> 단, 기록할 때 **「소리도 담기」를 골랐을 때만** 됩니다. 소리가 없으면
> 다시 셈할 것도 없습니다 — 그 기록에는 단추가 아예 안 보입니다.

## 7. 이 앱이 하지 않는 것

**할 수 있는 것만 적은 안내서는, 못 하는 일을 시키다 실패한 사람에게
「앱이 고장났다」는 결론을 줍니다.** 그래서 적어 둡니다.

- **법정 소음 측정을 대신하지 못합니다.** 형식승인·검정·정도검사나
  공인 교정을 갖춘 장비가 아닙니다.
- **공식 청력 안전기준이 아닙니다.** 앱이 보여 주는 참고 범위는
  그것과 다릅니다.
- **전달함수·위상·지연을 보지 않습니다.** FR 은 **크기만** 봅니다.
  스피커 정렬(딜레이 맞추기)에는 다른 도구가 필요합니다.
- **자동으로 EQ 를 걸어 주지 않습니다.** 어느 대역을 만질지는 **사람이**
  정합니다. 악기 EQ 는 **어디쯤인지**만 알려 줍니다.
- **하울링을 막아 주지 않습니다.** 후보를 **보여 줄** 뿐입니다.
- **보정하지 않은 절대 음압을 보장하지 않습니다.**

## 아직 채우지 못한 것 — **화면 그림**

이 안내서는 **글만** 있습니다. `PLAN.md` 가 「화면 그림 중심」으로
잡아 두었는데, 지금 있는 그림은 **개발 중 시험 자료 한 장뿐**이고
그것도 이름이 「이름 없음」이라 그대로 쓸 수 없습니다.

**현장에서 찍어야 할 것**(각 장의 첫 문단 옆에 들어갑니다):

| 장 | 무엇을 찍나 |
|---|---|
| 2. 측정 | 예배 중 SPL 화면 — 큰 숫자·Leq·권장 범위가 함께 보이게 |
| 2. 기록 | 「기록 중지」가 떠 있는 상태(기록 도는 중) |
| 3. RTA | 실제 찬양 중 31밴드(사무실에서 찍으면 밋밋합니다) |
| 3. Spectrogram | 하울링이 올라오는 순간 |
| 4. 악기 EQ | 악기를 고른 상태 — 띠가 밝아진 것이 보이게 |
| 5. 설정 | 보정 카드(「보정에 쓸 값」이 뜬 상태) |
| 6. 기록 | 시간축 그래프 + 다시 분석 카드 |

> **사무실에서 몰아 찍지 마십시오.** 조용한 방에서 찍은 곡선은 밋밋해서
> **설명하려는 것이 안 보입니다.**
